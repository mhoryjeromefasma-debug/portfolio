MHORY JEROME ASMA — PORTFOLIO (Multi-page)
==========================================
BUKSAN: i-extract ang ZIP, buksan ang index.html. (XAMPP: ilagay sa htdocs, tapos http://localhost/Mhory_Jerome_Asma_Portfolio/)
Kailangang magkakasama ang lahat ng file/folder.

MGA FILE (kanya-kanya)
  index.html      Home          css/home.css       js/home.js
  about.html      About         css/about.css
  strengths.html  Strengths     css/strengths.css
  projects.html   Projects      css/projects.css   js/projects.js
  approach.html   Approach      css/approach.css
  contact.html    Contact       css/contact.css    js/contact.js
  css/style.css   shared design (sidebar, buttons, transition)
  js/main.js      shared script (page transition, effects)
  js/config.js    <-- DITO ilagay ang totoong email mo

FEATURES
- Malaking menu sa kaliwa (walang numero); walang scroll ang bawat page sa laptop/desktop
- Page transition (yellow curtain + pangalan ng page) tuwing magpapalit ng page
- Next/Previous buttons at ← → keyboard keys
- Welcome intro (isang beses lang bawat session)
- Sa phone/maliit na screen: may menu button at pwedeng mag-scroll

PALITAN BAGO I-PUBLISH
- Email: js/config.js
- Social links: nasa sidebar ng bawat .html (hanapin ang instagram.com, facebook.com, atbp.)
- Idagdag ang totoong education, experience, at projects kapag meron na
